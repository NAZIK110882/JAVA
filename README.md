# Лабораторна робота №1: Система прокату автомобілів

## Опис предметної області
Цей проєкт є консольним застосунком мовою Java, який моделює базовий функціонал розрахунку вартості послуг у системі прокату автомобілів. 

**Ключова сутність:** Договір оренди.

Програма отримує від користувача такі характеристики сутності:
- Марка та модель автомобіля (`String`)
- Кількість днів прокату (`int`)
- Вартість оренди за один день у доларах (`double`)
- Розмір персональної знижки клієнта у відсотках (`double`)

**Обчислювальна операція:** 
На основі введених даних програма виконує розрахунок повної вартості оренди, вираховує суму знижки та формує остаточну суму до сплати. Результат виводиться у вигляді форматованого фінансового чека з точністю до двох знаків після коми.

## Інструкція із запуску

Для компіляції та запуску програми на вашому комп'ютері має бути встановлений Java Development Kit (JDK).

1. Відкрийте термінал (CLI) та перейдіть у директорію, де знаходиться файл `Main.java`.
2. Скомпілюйте вихідний код програми за допомогою команди:
   javac Main.java
Після успішної компіляції (створення файлу Main.class) запустіть програму командою:

Bash
java Main
