# Лабораторна робота №4: Реалізація програмних інтерфейсів мовою Java

**Предметна область:** Система прокату автомобілів (Car Rental System)

## Опис сутності
Проєкт демонструє використання інтерфейсів, абстрактних класів, та патерну Strategy. 
Система дозволяє розраховувати вартість оренди автомобілів залежно від обраної стратегії:
- `DailyPricingStrategy` — подобова оренда.
- `HourlyPricingStrategy` — погодинна оренда.

Також реалізовано абстрактний клас `AbstractVehicle`, що містить спільну логіку для транспортних засобів, та інтерфейс `Serviceable` для демонстрації множинної реалізації.

## Інструкція запуску
1. Відкрийте проєкт у середовищі розробки (наприклад, Visual Studio Code).
2. Переконайтеся, що встановлено Java Development Kit (JDK) та розширення *Extension Pack for Java*.
3. Відкрийте файл `Main.java`.
4. Натисніть кнопку **Run** (або запустіть через термінал командою `javac Main.java` та `java Main`).
5. Результат виконання програми (робота патерна Strategy та поліморфізм) виведеться в консоль.
