# Лабораторна робота №3: Обробка винятків

## Опис предметної області
Проєкт "Система прокату автомобілів". В цій роботі реалізовано захист програми від некоректних дій користувача та системних збоїв за допомогою механізму обробки винятків (Exception Handling).

Реалізовано:
1. **Ієрархію власних винятків:** 
   - Базовий клас `RentalException` (checked).
   - Підкласи `InvalidPriceException` та `InvalidDaysException`, які містять додаткові поля з некоректними даними.
2. **Множинну обробку (Multiple catch):** Перехоплення стандартних винятків (`InputMismatchException`, `ArrayIndexOutOfBoundsException`) та власних доменних з дотриманням ієрархії.
3. **Блок `finally`:** Для гарантованого закриття `Scanner`.
4. **Повторне збудження (re-throw):** Метод `createRentalWithLogging` частково обробляє виняток (логує) і прокидає його вище.

## Інструкція із запуску
1. Скомпілюйте всі Java файли:
   javac *.java
Запустіть програму:

java Main
