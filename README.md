# Лабораторна робота №2: Опрацювання масивів із застосуванням циклів

## Опис предметної області
Цей проєкт є продовженням розробки консольного застосунку для системи прокату автомобілів. У цій роботі реалізовано об'єктно-орієнтований підхід, роботу з масивами та базові алгоритми сортування і пошуку.

**Ключова сутність:** Договір оренди (окремий клас `CarRental`).

Програма реалізує наступний функціонал:
- **Опрацювання масивів:** Створення масиву об'єктів заданого розміру та його заповнення даними, які користувач вводить з клавіатури (використовується цикл `for`).
- **Виведення та аналіз:** Виведення всього списку договорів (через цикл `for-each`) та підрахунок кількості авто преміум-сегмента (вартість оренди понад $50/день).
- **Сортування (Bubble Sort):** Власноручна реалізація алгоритму "сортування бульбашкою" для впорядкування масиву договорів за зростанням ціни оренди за день.
- **Лінійний пошук:** Пошук конкретного договору в масиві за повним збігом об'єкта-зразка (з використанням спеціально перевизначеного методу `equals()`).

## Інструкція із запуску

Для компіляції та запуску програми на вашому комп'ютері має бути встановлений Java Development Kit (JDK).

1. Відкрийте термінал (CLI) та перейдіть у директорію проєкту, де знаходяться файли.
2. Скомпілюйте вихідний код програми (обидва файли) за допомогою команди:
   javac CarRental.java Main.java
Після успішної компіляції запустіть головний клас програми командою:
java Main
Дотримуйтесь інструкцій у консолі для введення кількості договорів та їх характеристик.
